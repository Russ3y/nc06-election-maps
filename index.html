How to read the election results map

What it shows: Each precinct is shaded according to its reported McDowell–Jefferson election result. The colors describe the congressional result in that geographic area, not the party registration of its residents.

How to use it: Use the map controls to zoom or pan, then select a precinct to view the reported votes and vote shares. Check the county outlines and any available television-market overlay to orient yourself.

05 / Interactive map

Precinct vote volume

Compare the number of reported votes in each precinct and explore the existing districtwide importance ranking.

How to read the precinct vote volume map

What it shows: This map displays the number of congressional votes reported in each precinct. It shows the size of the reported vote, not which candidate won or the number of registered voters.

How to use it: Zoom to a county and click a precinct to inspect its vote count and share of the districtwide reported vote. Compare nearby precincts using the legend.

Data note: Vote volume can be affected by how early and absentee votes were reported; it is not an official turnout rate.

How to read the registration map

What it shows: This map shows the distribution of active registered Republicans, Democrats, and unaffiliated voters. Party registration is not a record of how anyone voted.

How to use it: Choose a registration view using the map controls, zoom to a precinct, and click it for party counts and percentages. Compare the different views rather than interpreting one color as a candidate vote.

Data note: Registration comes from a separate snapshot and is not necessarily from Election Day.

Down-ballot performance and registration

Compare constitutional amendment results, state legislative candidates, party registration and approximate congressional vote-to-registration ratios by precinct. These are descriptive comparisons from preliminary precinct files, not estimates of persuadable voters.

How to read the down-ballot comparison map

What it shows: Select a constitutional amendment, NC House race, NC Senate race, registration measure, or the approximate congressional-votes-to-registration measure. Amendment layers compare the share voting “For” with McDowell’s share; legislative layers compare the Republican candidate’s share with McDowell’s share in the same reported precinct.

How to use it: Use the “Map measurement” dropdown in the map panel, then click a precinct. The detail panel shows its registration composition, congressional result, and available contest comparisons. A positive percentage-point gap means the selected measure had a higher vote share than McDowell; a negative gap means a lower share.

Data note: These are descriptive comparisons, not identified crossover voters or an estimate of votes available to gain. Contested and uncontested legislative races should not be interpreted alike; the preliminary precinct returns do not reconcile to the full congressional total.
